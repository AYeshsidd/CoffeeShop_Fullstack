## Overview

Coffee Shop is a full-stack web application inspired by modern cafés and coffee retailers. The project brings together a responsive storefront and a Python backend, providing practical experience in API design, authentication, database operations, and application architecture.

## Key Features

- **Responsive Storefront:** Modern UI built with Next.js, TypeScript, and Tailwind CSS.
- **UI Animations:** Motion effects using Framer Motion.
- **REST API:** Backend endpoints developed with FastAPI.
- **Authentication & Authorization:** JWT-based authentication with customer and admin roles.
- **Relational Database:** MySQL integration using SQLAlchemy ORM.
- **Database Migrations:** Schema versioning and migration management with Alembic.
- **Product & Category Management:** Backend functionality for organizing shop products.
- **Shopping Cart:** Cart functionality for the e-commerce experience.
- **Reusable Components:** Structured frontend components and consistent UI patterns.

## Project Deliverables

- A responsive coffee shop storefront.
- A FastAPI backend organized around REST endpoints.
- MySQL database integration through SQLAlchemy.
- JWT authentication and role-based authorization.
- Alembic-based database migration setup.
- Product, category, and shopping cart functionality.
